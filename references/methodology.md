# 反向指标方法论

## 核心理念

"峰哥反向指标"基于行为金融学中的**反向投资（Contrarian Investing）**理念，结合社交媒体情绪分析。其逻辑基础是：

> 当一位具有影响力的市场参与者的观点持续性地与市场实际走势相反时，其观点可以作为有效的反向参考信号。

## 心理学基础

1. **锚定效应**：峰哥可能锚定于特定价位或叙事，导致判断偏差
2. **过度自信**：频繁公开发言可能强化过度自信，降低判断准确率
3. **确认偏误**：粉丝互动可能强化其固有观点，形成"回声室"
4. **损失厌恶**：晒亏损后的极端言论往往是情绪低点，对应市场底部区域
5. **处置效应**：过早卖出盈利股、过久持有亏损股，导致"截断利润，让亏损奔跑"
6. **沉没成本谬误**：越跌越补直到满仓深套，因为"不甘心"而无法止损

## 分析方法

### 1. 文本特征分析

| 特征 | 看多信号词 | 看空信号词 |
|------|-----------|-----------|
| 操作类 | 加仓、买入、抄底、满仓、重仓、梭哈 | 减仓、清仓、卖出、割肉、空仓 |
| 预期类 | 大涨、暴涨、突破、起飞、牛市 | 大跌、暴跌、崩盘、完蛋、熊市 |
| 情绪类 | 牛逼、稳了、放心、吃肉 | 垃圾、废物、坑人、骗局 |
| 标的类 | 某股票名/代码、某板块名 | 某股票名/代码、某板块名 |
| 持仓类 | 晒盈利、晒持仓 | 晒亏损、晒割肉 |

### 2. 强度评分规则

```
强度评分 = 信号词密度 × 情绪强度系数 × 标的具体性系数
```

| 因素 | 高 (1.0) | 中 (0.5) | 低 (0.2) |
|------|---------|---------|---------|
| 信号词密度 | ≥3个信号词/条 | 1-2个信号词/条 | 无明确信号词 |
| 情绪强度 | 感叹号+情绪词+重复 | 有情绪词 | 中性表述 |
| 标的具体性 | 明确股票代码/名称 | 提及板块/行业 | 笼统描述 |
| 持仓证据 | 晒单截图/具体仓位 | 提及持仓无截图 | 未提及 |
| 频率 | 连续多日提及 | 偶尔提及 | 首次提及 |

### 3. 行为信号分析（权重高于文本）

行为信号分析峰哥的**实际行动**而非口头表达。行为比语言更真实，因为行动涉及真实资金和决策成本。

#### 行为信号清单

| 行为 | 类型 | 反向映射 | 权重倍率 |
|------|------|---------|:-------:|
| 卸载同花顺/删交易软件 | 离场 | 🟢 看多 | 3x |
| 重新安装/恢复看盘 | 回归 | 🔴 看空 | 3x |
| 销户/宣布永久退出 | 离场 | 🟢 看多 | 3x |
| 全仓买入/满仓梭哈 | 加仓 | 🔴 看空 | 2x |
| 一键清仓/全部卖掉 | 离场 | 🟢 看多 | 2x |
| 晒持仓盈利 | 炫耀 | 🔴 看空 | 2x |
| 晒亏损割肉图 | 崩溃 | 🟢 看多 | 2x |
| 连续多日沉默 | 躺平 | 🟢 看多 | 1x |
| 频繁发言/刷屏 | 亢奋 | 🔴 看空 | 1x |

#### 行为模式识别

峰哥的典型行为循环：
```
卸载/销户（底部）→ 沉默 → 偷偷装回软件 → 小仓位试水 → 
全仓买入（顶部）→ 被套 → 死扛 → 情绪崩溃 → 再次卸载/销户（底部）
```

在这个循环中：
- **卸载/销户阶段**：市场通常处于或接近底部 → 🟢 反向看多
- **全仓回归阶段**：市场通常处于或接近顶部 → 🔴 反向看空

### 5. 胜率统计方法

```
单次验证：观点日期 vs 后续N日走势（N=5/10/20/60交易日）
反向正确：峰哥看多 → 标的下跌 / 峰哥看空 → 标的上涨
反向错误：峰哥看多 → 标的上涨 / 峰哥看空 → 标的下跌

胜率 = 反向正确次数 / 总观点数 × 100%
```

## 风险控制

1. **信号衰减**：峰哥的观点影响力可能随时间变化，需持续验证
2. **自我实现**：如果太多人使用反向指标，可能自我失效
3. **样本偏差**：晒单可能选择性展示，不代表全部操作
4. **时效性**：旧观点的参考价值随时间递减
5. **黑天鹅**：极端行情下所有指标都可能失效
