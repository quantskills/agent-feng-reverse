# 数据来源与搜索策略

## 主要数据源：微博 (Weibo)

### WebSearch 搜索策略

使用以下搜索词获取峰哥亡命天涯的最新发言：

| 搜索词 | 用途 | 优先级 |
|-------|------|-------|
| `"峰哥亡命天涯" 微博` | 通用搜索最新微博 | ⭐⭐⭐ |
| `"峰哥亡命天涯" 股票` | 获取股票相关内容 | ⭐⭐⭐ |
| `"峰哥亡命天涯" site:weibo.com` | 直接从微博搜索 | ⭐⭐⭐ |
| `"峰哥亡命天涯" A股` | A股相关观点 | ⭐⭐ |
| `"峰哥亡命天涯" 大盘` | 大盘观点 | ⭐⭐ |
| `"峰哥亡命天涯" 加仓\|减仓\|清仓\|买入\|卖出` | 操作类内容 | ⭐⭐ |
| `"峰哥亡命天涯" 晒单\|持仓\|收益\|亏损` | 持仓曝光 | ⭐⭐ |
| `"峰哥亡命天涯" 板块\|行业\|概念` | 板块观点 | ⭐⭐ |

### 数据时效性

- WebSearch 结果通常有数小时到数天的延迟
- 如需实时数据，建议用户直接提供微博截图或链接
- 每日检查频率建议：盘中至少1次，盘后1次

## 辅助数据源

### 行情数据
通过 Pandadata API 获取涉及标的的行情数据，验证峰哥观点的准确性：
- `get_kline_daily` — 获取个股K线
- `get_market_index` — 获取大盘指数
- `get_stock_industry` — 获取个股所属板块

### 历史数据库
如果本地保存有峰哥的历史微博存档（JSON 格式），存放在 `references/history/` 目录下，可用于：
- 回测反向指标胜率
- 分析峰哥观点的演变
- 生成更准确的信号
